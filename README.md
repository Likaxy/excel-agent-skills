## 📦 What is excel-agent-skills?

excel-agent-skills is a set of tools designed to help you use Excel more effectively. These tools work quietly in the background to improve how Excel handles data and tasks. By using smart agents, the software helps manage your Excel files without slowing down or losing context, even with large data.

You do not need any programming or technical skills to get these tools running. They work on Windows and focus on keeping your work smooth and quick. Whether you want to automate repetitive Excel tasks or handle complex data better, excel-agent-skills can help.

- Manage Excel workbooks with less manual work.
